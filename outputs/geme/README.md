# GEME

Trang chủ cửa hàng trang sức GEME dựng bằng Next.js App Router. Đây là bản giao diện frontend tĩnh theo ảnh tham chiếu; dữ liệu sản phẩm, tìm kiếm và thanh toán chưa nối backend.

## Chạy dự án

```bash
pnpm install
pnpm dev
```

Mở `http://127.0.0.1:3000`.

Ảnh trong `public/assets` được cắt từ ảnh tham chiếu do người dùng cung cấp để giữ đúng art direction trong bản frontend đầu tiên.
